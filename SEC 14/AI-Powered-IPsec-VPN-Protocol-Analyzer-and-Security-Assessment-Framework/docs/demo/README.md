# Demo walkthrough (SIH 26160)

Generated by `scripts/demo_walkthrough.cjs` against a running backend (`127.0.0.1:8000`) and dev
frontend (`127.0.0.1:5173`). Everything shown comes from two **software-testbed** captures that were
pushed through the real pipeline — no data is mocked in the UI:

| Capture | Profile | What it demonstrates |
|---|---|---|
| Modern gateway | `PROFILE-01-TUNNEL-AES256GCM-PFS-IPV4` — IKEv2, AES-256-GCM, ECP-256, PFS, IPv4 tunnel | Strong suite graded **A** from the observed `IKE_SA_INIT`; IETF and NIST profiles compliant, CNSA 1.0 not (ECP-256 < ECP-384) |
| Legacy baseline | `PROFILE-05-TUNNEL-3DESCBC-NOPFS-IPV4` — IKEv1 aggressive mode, 3DES-CBC, HMAC-MD5, MODP-1024, no PFS | Grade **F**, every profile non-compliant, nine explainable findings, what-if remediation from 48 → 85+ |

## Reproduce

```bash
# terminal 1 — backend (fresh SQLite so the demo starts empty)
cd "SEC 14/AI-Powered-IPsec-VPN-Protocol-Analyzer-and-Security-Assessment-Framework/backend"
DATABASE_URL=sqlite:////tmp/ipsec-demo.db APPLICATION_MODE=STANDALONE python -m uvicorn app.main:app --port 8000

# terminal 2 — frontend
cd "SEC 14/AI-Powered-IPsec-VPN-Protocol-Analyzer-and-Security-Assessment-Framework/frontend" && npm run dev

# terminal 3 — walkthrough (needs Playwright + Chromium: npm i -g playwright && npx playwright install chromium)
cd "SEC 14/AI-Powered-IPsec-VPN-Protocol-Analyzer-and-Security-Assessment-Framework"
NODE_PATH="$(npm root -g)" node scripts/demo_walkthrough.cjs
```

Seeded sign-in: `analyst` / `Analyst@2026!` (created by `backend/app/db/init_db.py` on first start; change it before any
deployment).
